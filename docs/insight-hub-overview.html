SCCC Network Insight Hub

IT Operations & AI Intelligence Platform  |  Confidential — IT Division

The Network Insight Hub is SCCC's centralized IT operations platform, providing real-time visibility into network infrastructure, AI-assisted operations, automated documentation, and a live physical topology map of the campus network. It is hosted on a secured Azure virtual machine and accessed exclusively through the college's Single Sign-On identity provider.

Core Capabilities

  • Live device inventory & status dashboard
  • Physical topology map (LLDP/CDP sourced)
  • Network visualizer with building grouping
  • Device config archive & diff viewer
  • Incident room & dispatch coordination
  • Automated VLAN & switch documentation

Access & Security

  • Azure AD SSO — SCCC credentials only
  • Role-based access: Viewer / Network Admin / CIO
  • All traffic over HTTPS (TLS 1.2+)
  • SNMP restricted to RFC-1918 ranges
  • Device secrets redacted in UI display
  • Audit log on all configuration changes

🤖 FRED — Field Response & Engineering Dashboard

FRED is the AI assistant embedded in the Hub. It answers natural-language questions about the network ("which switches feed AA144?"), generates incident summaries, suggests diagnostic steps, interprets LLDP topology data, and drafts change-request documentation — all from within the platform without leaving the browser.

Access & Integration Architecture

Deployment

  • Azure VM — Standard_B2s, Ubuntu 22.04
  • Node.js API server + React SPA (Vite)
  • PostgreSQL 15 (local, VM-hosted)
  • PM2 process manager, systemd on-boot
  • GitHub → git pull deploy workflow

Roadmap

  • Automated LLDP polling (cron + collect-lldp.py)
  • Full campus topology from all switches
  • OSPF/BGP adjacency map overlay
  • Incident alerting & escalation workflow
  • SCCCACR academic continuity integration
